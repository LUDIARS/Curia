ANTHROPIC_API_KEY は環境変数での指定を推奨 (config には保存しません)。

Thaleia

Anatomia / Praeforma / Discutere の接続先は Curia が自動で渡します (curia.apps.json で無効にしたアプリの接続先は渡しません)。ここで指定するのは Curia が起動しない上流だけです。空欄の上流は評価でその軸が missing になります。

Voluptas

データリポジトリや Name の設定は Voluptas タブ内の Settings 画面で行います (正本 = %LOCALAPPDATA%/Volputas/local-config.json)。
